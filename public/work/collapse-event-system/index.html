04 / INTERFACE CHOICESUI / UX

Designed for
the moment of entry.

The visual language belongs to COLLAPSE. The hierarchy follows the operator’s task: identify the invitation, read its status and choose the next action.

01 / HIERARCHY

One main action.

The light confirmation button stands out against the dark interface. Ticket details sit next to the result, so the operator can check them before confirming.

02 / STATUS

States you can read.

Valid and already-used invitations are distinguished by explicit wording as well as colour. The status explains what has happened before the next action.

03 / MOBILE

The same flow, in hand.

The original application includes desktop and mobile scanner views. The invitation is delivered as a digital ticket, ready to display from a phone.
