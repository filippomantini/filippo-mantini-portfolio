01 / CONTEXT

FROM EVENT
FRICTION TO FLOW.

The system was created around the practical needs of running Collapse events: generating tickets, separating guest types and controlling access quickly at the door.

The interface turns a set of operational tasks into one clear flow, reducing manual checks while keeping the experience simple for the people using it live.

02 / SYSTEM

ONE SYSTEM,
MULTIPLE ROLES.

The product connects ticket creation, QR codes, scanning, VIP and guest categories, admissions and timestamps.

The design challenge is not visual complexity but clarity under pressure: information has to be readable and actions have to be fast during a live event.
