COLLAPSE
EVENT SYSTEM

THE APP THAT BRINGS
ORDER TO THE CHAOS.

I built an application to manage a private COLLAPSE event at a villa: from setting up the guest list to designing tickets, scanning QR codes and tracking entrances during the evening.

ROLE

Concept, UI/UX, application design and development, ticket graphics and guest entry workflow.

THE CONTEXT

An event with different categories of attendees needed individual invitations, fast check-in and clear attendance tracking for guests, VIPs and DJs.
