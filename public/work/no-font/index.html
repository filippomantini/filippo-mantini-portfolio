NO FONT

A typographic research project built around letterforms, construction and the boundary between type and image.

RoleGraphic Design

TYPE CAN START BEFORE A FONT EXISTS.
01 / CONTEXT

LETTERFORM AS
EXPERIMENT.

The project investigates type as a visual object before treating it as a finished font system.

Form, rhythm and repetition become the main tools for testing how letters can behave.

02 / SYSTEM

FROM FORM
TO ALPHABET.

The work develops through a sequence of studies rather than a single final mark.

The original project archive will be added here as a progression from sketches and form tests to the final typographic output.
