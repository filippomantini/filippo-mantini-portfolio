01 / CONTEXT

AN IDENTITY
BUILT FOR ENERGY.

The project brings graphic identity and live-event image-making into the same visual language.

The identity needs to work before the event, through social communication, and after it, through the photographic archive.

02 / SYSTEM

FROM MARK
TO MOMENT.

Logo, social assets and photography are treated as connected parts of the same communication system.

The project is structured around recognisable visual cues that can survive across static graphics and live documentation.
