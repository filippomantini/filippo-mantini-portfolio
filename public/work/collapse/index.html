COLLAPSE

Collapse is an evolving fashion and cultural project built as a connected visual world across identity, fashion, campaigns, events and a website designed and managed as part of the brand experience.

01 / CONTEXT

AN IDENTITY
THAT MOVES.

The project grows through clothing, campaigns, photography, video, collaborations and physical events. Each output belongs to the same identity, but the system is allowed to change with the context.

The work combines brand direction with ongoing experimentation, using repetition, tension and controlled inconsistency to keep the project recognisable without making it static.

02 / SYSTEM

ONE WORLD,
MANY FORMATS.

The identity is developed across product graphics, editorial imagery, moving image, social content, event communication and the Collapse website.

Rather than treating each medium separately, Collapse uses them as parts of the same system: product creates image, image creates narrative, and narrative creates community.

BUILT BEYOND
THE GARMENT.

The project extends beyond fashion through exhibitions, collaborations, events and cultural programming.

Rebuild Yourself and the Collapse Event System are examples of how the brand language expands into physical and digital experiences.
