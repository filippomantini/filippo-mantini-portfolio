# No Font web prototype 0.1

Original letterforms by Filippo Mantini. Converted from the vector outlines on page 2 of the author-provided `font specimen.ai` (PDF-compatible Illustrator file, 13 pages). No glyphs redrawn or borrowed. The orange X is an editorial overlay and is excluded. Black additions and white cutouts are combined with path booleans before cubic-to-quadratic conversion.

82 Unicode characters, including space. Only the accents and signs present in the original specimen are included. Initial 55-unit sidebearings, 700-unit cap height, no kerning. This is a portfolio proof, not a finished production type family. Distribution terms remain for the author to define.

Rebuild: `python scripts/type-sources/build_no_font.py /path/to/font-specimen.ai /path/to/output`. Dependencies are documented in the script. The private editable source is not included in the public repository. `no-font-glyph-source-map.json` records each glyph and its source drawing indices.
